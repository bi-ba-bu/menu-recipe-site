# 今日食堂 · 菜单与食谱

一个**同时适配 Web 端与 App 端**的菜单 / 食谱应用。前端零框架、零构建；后端为 Python 标准库实现，数据以 JSON 文件存储。

## 快速开始

```bash
# 启动后端（同时托管前端页面）
python server/run.py

# 浏览器访问 http://127.0.0.1:5188/
```

后端未启动时页面仍可打开，会自动降级为浏览器本地模式（顶栏显示「本地模式」）。

可选参数与接口文档见 [server/README.md](server/README.md)。

## 双端适配方案

移动优先（mobile-first）：基础样式按 App 端设计，通过 `min-width` 断点向上增强为 Web 形态。

| 断点 | 形态 | 导航 | 布局特征 |
| --- | --- | --- | --- |
| `< 640px` | 手机 App | 底部 TabBar + 侧滑抽屉 | 单列菜品卡、大触控区（≥44px）、安全区适配 |
| `640px – 1023px` | 平板 | 底部 TabBar + 侧滑抽屉 | 菜品双列、食材双列、搜索框展开 |
| `≥ 1024px` | 桌面 Web | 常驻左侧栏 | 菜品三列、食谱页双栏 + 粘性侧边栏、悬停动效 |

关键适配细节：

- **安全区**：`env(safe-area-inset-*)` 处理刘海屏与 home indicator，TabBar 与顶栏自动避让。
- **触控尺寸**：`:root` 下所有可点击元素不小于 44×44；`@media (pointer: coarse)` 额外放大图标按钮。
- **悬停降级**：`@media (hover: none)` 关闭仅适合鼠标的悬停位移效果，避免触屏"粘滞悬停"。
- **字体缩放**：标题使用 `clamp()` 随视口平滑变化，避免断点处突跳。
- **横滚防溢出**：星期 tab 使用 `overflow-x: auto` 局部横滚，页面本身在 375px 下无横向溢出。

## 功能

- **一周菜单**：7 天 × 早/午/晚三餐，每日热量汇总，当前日高亮
- **点餐**：39 道菜品的橱窗，可按分类 / 关键词筛选；每张卡片选好「星期 + 餐次」后点「加入」，即可把菜品排进本周某天某餐
- **食谱详情**：头图、难度/时长/份量、营养拆解、食材清单（主料高亮）、分步时间轴、小贴士
- **营养概览**：纯 CSS 柱状图（热量 + 蛋白质）、每日完成度进度条、饮水环形图
- **我的收藏**：星标收藏，`localStorage` 持久化，侧栏徽标计数同步
- **搜索**：按菜名与食材名过滤
- **深色模式**：跟随系统，也可手动切换并记住选择
- **无障碍**：语义化标签、`aria-pressed` / `aria-selected` 状态、键盘可达（Enter/Space 打开、Esc 关闭抽屉）、`prefers-reduced-motion` 降级

## 点餐功能说明

点餐是「菜品 → 某天某餐」的编排，数据模型如下：

```js
orders = {
  mon: { breakfast: [{ id: 'oat-congee', qty: 1 }], lunch: [...], dinner: [...] },
  tue: { ... }, // … sun
}
```

交互链路：

1. 在「点餐」页挑选菜品，每张卡片底部选择目标（默认今天 + 午餐），点「加入」
2. 同一天同一餐重复加入同一道菜时，数量自动累加（不产生重复条目）
3. 右侧「本周点餐」按星期分组，可调整数量（减到 0 自动移除）或删除单条
4. 点「确认本周菜单」→ 弹窗按天预览 → 提交后同步写回「一周菜单」视图
5. 订单写入 `localStorage`，刷新 / 重开浏览器都不丢

双端形态差异：

| 断点 | 点餐篮形态 |
| --- | --- |
| `< 1024px` | 收进底部抽屉，页面底部有悬浮操作条显示「已点 N 道」，点开后从底部滑出 |
| `≥ 1024px` | 常驻右侧栏，随页面滚动保持粘性定位 |

未在点餐里安排的餐次，会保留 `data.js` 里的示例菜单，不会被清空。

## 替换数据

编辑 `js/data.js` 即可，保持字段结构不变：

- `MENU_WEEKS`：菜单结构，`meals` 下每道菜的 `id` 需能在 `RECIPES` 中找到
- `RECIPES`：食谱详情，key 与菜单 `dishId` 对应
- `NUTRITION` / `TODAY_OVERVIEW`：营养概览与今日数据
- `TAG_META`：标签中文名与配色

新增菜品时，如需自定义缩略图图标，在 `js/icons.js` 的 `DISH_ICON` 中登记 `{ icon, fg, bg }`，未登记的会自动回落到通用图标。

## 设计说明

- 图标全部使用**内联 SVG**，不依赖 emoji。原因：不同系统对 emoji 的渲染差异大（部分设备显示为黑白剪影或不支持），作为菜品缩略图不可控。
- 交互不引入任何第三方库，图表用 CSS 实现，便于嵌入任意宿主（含 Electron）。
- 颜色全部走 CSS 变量，换主题只需改 `:root` 中的令牌。
