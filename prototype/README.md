# 可爱风改版 · 设计稿

> 这是一份**评审用原型**，不影响现有页面。现有 `index.html` / `css/main.css` / `js/*` 一行未改。

## 怎么看

后端已在跑时，直接打开：

```
http://127.0.0.1:5188/prototype/
```

页面顶部有一条粉色说明栏，可以直接跳到各页；点最右侧的 `×` 可以隐藏说明栏看整屏效果。

> 原型与真实页面同源，所以**共用同一份登录态**。没登录会看到登录页，登录后就是真实数据。

想换头像组合，可以在地址后面加参数：

```
/prototype/?members=妈妈,爸爸,小朋友
```

## 改了什么

### 1. 配色：暖橙「餐厅感」→ 草莓奶油「糖果感」

| 角色 | 原来 | 现在 |
| --- | --- | --- |
| 背景 | 暖米灰 `#f6f4f0` | 奶油粉底 `#fff7f2` + 粉/蓝/黄三处柔光晕 |
| 主色 | 番茄橙 `#e0654a` | 草莓粉 `#ff7fa5` |
| 辅色 | 绿 / 蓝 / 黄 | 薄荷青柠 `#5ccfb0`、蜂蜜黄 `#ffc247`、葡萄紫 `#a78bfa` |
| 文字 | 近黑 `#1f2328` | 巧克力紫 `#4a3f52`（黑度更低，更软） |
| 投影 | 灰色阴影 | 粉色柔光阴影 `rgba(255,143,168,.18)` |

### 2. 形状：直角感 → 充气感

- 圆角从 8/12/16px 提到 14/20/26/34px，卡片像软糖一样鼓起来
- 按钮、标签、输入框、步骤序号统一 `999px` 胶囊
- 虚线描边替代实线分割线（区域之间用「虚线」而不是「硬线」）
- 悬停位移从 2px 提到 4px，并带 0.3° 的轻微倾斜，像贴纸被捏了一下

### 3. 头像：单字圆点 → Q 版卡通（重点需求）

**同一个家庭，主卡上并排两张卡通头像。**

- 造型：手绘 SVG，6 个形象（妈妈 / 爸爸 / 小朋友 / 奶奶 / 爷爷 / 猫咪）
- 匹配规则：按成员昵称里的关键词自动选形象（含"妈"→妈妈，"爸"→爸爸，"宝/小/娃"→小朋友…），匹配不到按顺序错开，保证两个人不撞脸
- 头像位里穿插一颗飘动的小心心，右上角有闪烁的星芒；两张头像有 0.6s 相位差的上下浮动
- **成员只有 1 人时**：放「本人 + 一只猫咪」，猫咪当"今天的饭搭子"，避免主卡只剩一张图显空
- 成员行：每人一个专属小头像
- 家庭切换列表：每项左侧一对迷你头像

> 演示数据里「厨师的家庭」只有 1 名成员，为了让你看到"两人家庭"的完整样子，原型对这个家庭默认展示「妈妈 + 爸爸」。成员 ≥2 时永远用真实名字。给地址加 `?demo=0` 即可关闭。

### 4. 细节彩蛋

- 品牌 logo 微微歪 4°，右上角一颗闪烁小星
- 今日概览卡右上角一颗草莓贴纸
- 侧栏小提示卡改成便签纸样式（旋转 -1°，左上角一个四叶草）
- 菜单里的星期 tab 选中时上浮 4px
- 已被点过的菜品卡右上角一条薄荷色斜角绶带「已点 ✓」
- 页面左右各一团柔光光斑，随滚动固定不动

## 主题切换（已移到家庭设置）

原来主题按钮在顶栏右侧（一个小太阳/月亮图标），现在**搬到了「家庭设置」页里**，做成两个可视化选项卡片：

- 每个卡片带四色预览块（底色 / 卡片底 / 主色 / 辅色），一眼看出两套风格
- **只保留这两种主题**：浅色「奶油草莓」、深色「夜间软糖」，没有引入第三种
- 选中的卡片描粉边 + 右上角对勾，右上角还有「当前：深色」的文字说明
- 选择会记在本机（沿用原来的 `menu-recipe-theme` 键），下次打开自动恢复
- 没手动选过时跟随系统偏好；系统切换主题时面板会实时跟着变
- 顶栏原来的太阳/月亮按钮在原型里已隐藏，避免两个入口互相打架

> 键盘用户注意：卡片里藏的是原生 `radio`，可以用 Tab 聚焦、方向键切换，
> 聚焦时整张卡会描边，屏幕阅读器会正确播报「已选中」。

## 兼容性

- **双端**：移动端（<640px）家庭主卡变成「头像 + 名字」上下两行、徽章换行；桌面端（≥1024px）头像放大到 88/100px
- **深色模式**：另做了一套「夜间软糖」配色（深紫底 + 提亮粉），不是简单反色
- **减少动效**：`prefers-reduced-motion` 下关闭所有浮动/闪烁
- **不引外部资源**：图标、头像全是内联 SVG，字体走系统圆体栈（评审现场断网也能看）

```
├── avatars.js     # ★ Q 版头像 SVG 与形象匹配规则
├── theme.js       # ★ 主题切换：两个选项卡片、读写 localStorage、状态同步
└── icons.js       # 原型专用图标增量（太阳 / 月亮 / 调色盘）
```

## 如果决定采用，落地方式

1. `cute.css` 作为 `css/main.css` 之后的一层皮肤引入（HTML 里加一行 `<link>`）
2. `avatars.js` 接到 `js/icons.js` 旁边，家庭页渲染时把 `.family-hero__avatar` 换成 `cutePairHtml()`
3. `theme.js` 接到 `js/app.js` 旁边，在 `renderFamilyPage()` 的 HTML 里插入 `themePickerHtml()`，
   渲染完成后调一次 `bindThemePicker()`；同时删掉 `index.html` 顶栏里那个 `#themeToggle` 按钮
   和 app.js 里对应的 click 监听

不需要改任何数据接口。
